# 桌面提醒公共栏

桌面提醒公共栏是一款 Windows 本地桌面待办、提醒、公告通知和交接班工具。它适合前台、办公室值班、店铺员工、家庭成员、宿舍或共享电脑等场景，目标是做一个功能单一、无广告、无账号、无云同步、完全本地保存的小工具。

当前版本使用 Tauri 2 + Rust + HTML/CSS/JavaScript 开发，数据默认保存在本机，不需要登录，也不会主动上传到网络。

- [下载安装包：桌面提醒公共栏_0.1.0_x64-setup.exe](downloads/桌面提醒公共栏_0.1.0_x64-setup.exe)
- [下载绿色版：桌面提醒公共栏_0.1.0_x64-portable.zip](downloads/桌面提醒公共栏_0.1.0_x64-portable.zip)

## 系统要求

- Windows 10 / Windows 11
- 64 位系统
- Microsoft Edge WebView2 Runtime

Tauri 程序不像 Electron 那样自带完整 Chromium 浏览器内核，它会使用 Windows 系统里的 WebView2 来显示界面，所以程序体积更小。安装包通常会处理 WebView2；如果使用绿色版，目标电脑需要已经安装 WebView2 Runtime。

## 适用场景

- 个人电脑：记录桌面待办、到点提醒、未完成事项。
- 店铺或前台：多人共用一台电脑，记录值班事项和公共提醒。
- 办公室值班：上一班留下未完成事项，下一班确认接班。
- 家庭共享电脑：把家务、缴费、提醒和公共通知放在同一个桌面面板里。
- 不希望数据上云的场景：本地保存，不注册，不登录，不同步。

## 主要功能

- 桌面常驻面板：右侧小窗口显示当前桌面事项。
- 本地待办：支持内容、分类、创建人、负责人、优先级、提醒时间、截止时间和备注。
- 自然语言时间识别：在内容里输入“明天上午10点”“下周一下午3点”等，会自动识别提醒时间。
- 弹窗提醒：到点后弹出提醒列表，需要处理后才消失。
- 声音提醒：内置多种提醒音，也支持选择本地音频文件。
- 稍后提醒：支持稍后 5 分钟、30 分钟。
- 管理员通知：管理员发布公告通知后，需要全员确认。
- 交接班：接班人确认后记录交接历史，多人模式下未完成事项可转为交接事项。
- 历史记录：记录新增、修改、完成、确认、交接等操作痕迹。
- 管理员密码：后台设置、删除、恢复备份等操作需要管理员密码。
- 自动备份：定时备份本地数据文件。
- 托盘隐藏：关闭窗口时隐藏到 Windows 右下角托盘，不直接退出程序。

## 第一次使用

第一次打开软件时会进入初始化向导，建议依次设置：

1. 使用模式：单人模式或多人模式。
2. 超级管理员姓名和密码。
3. 安全问题，用于忘记密码时重置。
4. 人员名单。
5. 分类和班次。
6. 面板位置和显示方式。

设置完成后，软件会进入主界面。普通使用时可以直接新增待办、完成待办、查看通知和确认交接。

## 界面结构

- 待办：查看当前待办事项。
- 通知：查看管理员通知和全员确认进度。
- 交接：接班确认和最近交接记录。
- 设置：管理员后台、人员、分类、声音、面板、备份和历史记录。
- 新增待办：通过主按钮打开新增窗口。

## 数据保存和隐私

软件数据保存在本机，不会主动上传到服务器。

开发模式下，数据通常保存在项目目录的 `data/` 文件夹。打包后的 exe 版本，数据通常保存在 exe 同目录或用户选择的数据目录中。

主要数据文件可能包含：

```text
data/board-data.json
桌面提醒公共栏.db
```

这些文件可能包含人员名单、待办事项、历史记录、密码哈希和备份信息。公开项目或反馈问题时，不要上传自己的 `data/` 文件夹或真实业务数据库。

## 开发环境

如果你想从源码运行或继续开发，需要安装：

- Node.js
- Rust / Cargo
- Visual Studio C++ Build Tools
- Microsoft Edge WebView2 Runtime

安装依赖：

```powershell
npm.cmd install
```

开发运行：

```powershell
npm.cmd run dev
```

构建绿色 exe：

```powershell
npm.cmd run build
```

构建 Windows 安装包：

```powershell
npm.cmd run build:installer
```

构建产物默认位于：

```text
src-tauri/target/release/
src-tauri/target/release/bundle/nsis/
```

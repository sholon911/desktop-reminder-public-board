# 桌面提醒公共栏

桌面提醒公共栏是一款 Windows 本地桌面待办、提醒和交接班工具。它面向前台、办公室值班、店铺员工、家庭或共享电脑等场景，目标是做一个功能单一、无广告、无需账号、完全本地保存的小工具。

项目使用 Tauri 2 + Rust + HTML/CSS/JavaScript 开发。数据默认保存在本机，不需要联网、不注册、不登录。

## 适用场景

- 个人电脑：记录桌面待办、到点提醒、重复查看未完成事项。
- 店铺或前台：多人共用一台电脑，记录值班事项和交接提醒。
- 办公室值班：上一班留下未完成事项，下一班确认接班。
- 家庭共享电脑：把事项、提醒、公共通知放在同一个桌面面板里。
- 需要本地化和隐私的场景：不使用云同步，不上传数据。

## 主要功能

- 桌面常驻面板：右侧小窗口显示当前待办。
- 本地待办：支持内容、分类、负责人、创建人、优先级、提醒时间、截止时间、备注。
- 自然语言时间识别：在内容里输入“明天早上10点”“下周一下午3点”等，会自动填入提醒时间。
- 弹窗提醒：到点后弹出提醒列表，必须处理后才消失。
- 声音提醒：内置多种提醒音，也支持选择本地音频文件。
- 稍后提醒：支持稍后 5 分钟、30 分钟。
- 完成状态：事项完成后保留记录。
- 管理员通知：管理员发布通知，需要全员确认。
- 交接班：接班人确认后记录交接历史，多人模式下未完成事项可转为交接事项。
- 历史记录：记录新增、修改、完成、确认、交接等操作。
- 管理员密码：后台设置、删除、恢复备份等操作需要管理员密码。
- 自动备份：本机定时备份数据文件。
- 托盘隐藏：关闭窗口时隐藏到 Windows 右下角托盘，不直接退出。

## 界面结构

- 待办：查看当前待办，支持搜索和优先级筛选。
- 通知：查看管理员通知和全员确认进度。
- 交接：接班确认和最近交接记录。
- 设置：管理员后台、人员分类、声音、面板、备份和历史记录。
- 新增待办：通过右下角 `+` 按钮或 `Ctrl+N` 打开。

## 数据保存

软件数据保存在本机：

- 开发模式：项目目录下的 `data/`
- 打包后的 exe：exe 同目录下的 `data/`

主要数据文件：

```text
data/board-data.json
```

这个文件可能包含人员名单、待办事项、历史记录、密码哈希和备份信息。发布 GitHub 或反馈问题时，不要上传自己的 `data/` 文件夹。

## 系统要求

- Windows 10 / Windows 11
- x64 系统
- Microsoft Edge WebView2 Runtime

Tauri 不像 Electron 那样自带完整 Chromium 浏览器内核，它会使用系统里的 WebView2 来显示界面。因此：

- Tauri 程序体积更小。
- 目标电脑需要 WebView2 Runtime。
- 安装包会在安装过程中处理 WebView2。
- 如果只使用绿色 exe，目标电脑需要已经安装 WebView2 Evergreen Runtime x64。

## 开发环境

需要安装：

- Node.js
- Rust / Cargo
- Visual Studio C++ Build Tools
- Microsoft Edge WebView2 Runtime

安装前端依赖：

```powershell
npm.cmd install
```

开发运行：

```powershell
npm.cmd run dev
```

构建绿色 exe：

```powershell
npm.cmd run build
```

构建 Windows 安装包：

```powershell
npm.cmd run build:installer
```

构建产物默认位于：

```text
src-tauri/target/release/
src-tauri/target/release/bundle/nsis/
```

## GitHub 发布建议

源码仓库只提交源码和说明文件，不提交本地数据和安装包。

不要提交：

- `data/`
- `release-tauri/`
- `release-tauri-外发版/`
- `node_modules/`
- `src-tauri/target/`
- `*.exe`
- `*.msi`
- `*.log`

安装包建议放在 GitHub Releases，而不是直接提交到仓库。

推荐 Release 文件：

```text
桌面提醒公共栏_0.1.0_x64-setup.exe
```

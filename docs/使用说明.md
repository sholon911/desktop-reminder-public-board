# 使用说明

本文面向普通使用者，说明桌面提醒公共栏的应用场景、基础使用方法和注意事项。

## 软件用途

桌面提醒公共栏适合放在 Windows 桌面上，用来记录待办事项、到点提醒、管理员通知和交接班记录。它不是复杂项目管理软件，也不是云同步待办工具，重点是本地、简单、清楚、少打扰。

典型场景：

- 前台每天记录房租、水电、卫生、客户跟进。
- 店铺早班和晚班交接未完成事项。
- 办公室值班人员确认上一班留下的问题。
- 家庭成员共用电脑，记录公共事项。
- 个人电脑开机后自动看到今天要做的事。

## 第一次打开

第一次打开软件会进入初始化向导，需要设置：

- 使用模式：单人模式或多人模式。
- 超级管理员姓名。
- 管理员密码。
- 安全问题和答案。
- 人员名单。
- 待办分类。

初始化完成后，软件会保存本机数据。以后再次打开，不会重复要求设置管理员密码。

## 待办事项

点击右下角 `+` 按钮可以新增待办，也可以使用快捷键 `Ctrl+N`。

待办支持：

- 内容
- 分类
- 优先级：普通、重要、紧急
- 创建人
- 负责人
- 提醒对象：负责人或所有人
- 重复规则
- 提醒时间
- 截止时间
- 备注

如果待办过期，会显示为红色并置顶。

## 自然语言提醒时间

新增待办时，可以直接在内容里写时间，例如：

```text
明天早上10点给6058抄电表算房租
下周一下午3点检查卫生
6/30 18:00 提醒交房租
```

如果识别成功，软件会自动把提醒时间填入时间栏，并把内容里的时间删掉，只保留真正的事项内容。

如果识别失败，软件会保留完整输入内容。

## 提醒弹窗

到达提醒时间后，软件会弹出提醒窗口并播放声音。

提醒弹窗支持：

- 知道了
- 稍后 5 分钟
- 稍后 30 分钟
- 标记完成
- 打开详情

如果没有点击处理，提醒窗口会继续保持，之后会再次提醒。

## 管理员通知

管理员可以在设置页发布通知。通知适合用于：

- 店内公告
- 安全检查要求
- 当天必须确认的注意事项
- 所有人都要知道的信息

管理员通知需要所有启用人员确认后才算完成。

通知卡片会显示确认进度，例如：

```text
张三 已确认
李四 未确认
王五 已确认
```

## 交接班

多人模式下，接班人可以进入“交接”页点击确认接班。

确认后系统会记录：

- 接班人
- 班次
- 确认时间

多人模式下，未完成事项会转为交接事项，方便下一班继续处理。

## 设置和后台

设置页需要管理员密码。后台可以管理：

- 管理员通知
- 人员名单
- 分类
- 使用模式
- 提醒声音
- 面板颜色
- 备份
- 历史记录

普通使用者可以新增、完成、确认交接和确认通知；管理员用于处理更敏感的设置和删除操作。

## 数据和备份

软件数据保存在本机，不上传到网络。

如果使用绿色版 exe，数据在 exe 同目录的：

```text
data/board-data.json
```

迁移到其他电脑时，如果要保留旧数据，需要一起复制：

```text
桌面提醒公共栏-Tauri.exe
data/
```

如果希望新电脑重新初始化，不要复制 `data/` 文件夹。

## 常见问题

### 双击没反应怎么办？

优先使用安装包：

```text
桌面提醒公共栏_0.1.0_x64-setup.exe
```

如果绿色 exe 双击没反应，运行同目录下的：

```text
启动排错.bat
```

如果生成 `startup-error.log`，把日志发给开发者排查。

### 为什么需要 WebView2？

Tauri 使用 Windows 系统里的 Microsoft Edge WebView2 Runtime 显示界面。这样软件体积小，但目标电脑需要安装 WebView2。

安装包会处理 WebView2；绿色 exe 要求电脑已经安装 WebView2 Evergreen Runtime x64。

### 关闭窗口是不是退出程序？

不是。关闭窗口会隐藏到 Windows 右下角托盘，提醒功能仍然运行。需要完全退出时，可以从托盘菜单退出。

### 数据会不会上传？

不会。软件默认完全本地保存，不需要账号，不联网同步。
